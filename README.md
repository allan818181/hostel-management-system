## Overview

RoomSync hostel management system in PHP + MySQL: students register and book rooms; admins manage rooms, users and availability.

## Features

- Student registration, login and room booking
- Student dashboard showing their booking
- Admin login with room and user management (add, edit, delete)
- Room availability tracking

## Tech stack

PHP · MySQL · HTML5 · CSS3

## Getting started

1. Install [XAMPP](https://www.apachefriends.org/) (Apache + PHP + MySQL).
2. Copy this folder into `htdocs/`.
3. Create a MySQL database in phpMyAdmin and update the connection settings (`hostel/db.php`).
4. Open `http://localhost/hostel//` in your browser.

## Project structure

`hostel/admin` admin pages · `hostel/student` student pages · `hostel/db.php` database connection
